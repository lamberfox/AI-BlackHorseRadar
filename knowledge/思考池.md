# 📌 项目代号：TicketSanctuary（赛博门票圣殿）

### 🏷️ 核心标签

`#推活/OshiKatsu` `#年轻女性刚需` `#Flutter高颜值` `#AI多模态套利` `#私密双人羁绊`

## 1. 市场痛点与用户画像：从“表单工具”到“赛博供奉”

- **卡住了谁的刚需？**
    
    - **核心盘**：海外（日本“推活”OshiKatsu圈、欧美 Fandom 圈、Live 狂热者）16-30 岁的年轻女性。
        
    - **行为特征**：她们愿意为爱豆、现场、旅行砸下重金。纸质门票会褪色（热敏纸的宿命），而这些票根是她们与青春、朋友、爱豆同频共振的“唯一实体物证”。
        
- **为什么传统日历/记账/公共社区满足不了她们？**
    
    - **日历/记账 App**：太素、太理工男、充满表单输入的无情机械感，**毫无仪式感**。
        
    - **公共社区（小红书/X/Instagram）**：太喧嚣，充斥着算法焦虑、点赞攀比和饭圈撕扯。
        
- **我们的降维打击点**：
    
    - **极致私密性**：绝不做公开社区。定位是 **“单人圣殿 或 双人/多人私密羁绊空间”**。
        
    - **情感资产化**：和谁一起去的，邀请对方加入这个 Ticket Box，两人共同擦亮这张卡片，在“人生足迹地图”上拉出一条带着糖果粒子的连线。
        

## 2. AI 升维点：干掉输入惰性，资产“起死回生”

用户极其讨厌繁琐的手动填表，我们要用自动化 AI Pipeline 实现“一键成卡”。

代码段

```
graph LR
    A[用户拍张照/传老旧票根] --> B(DeepSeek-VL 多模态提取)
    B --> C{结构化数据 JSON}
    C --> D[COS 拼装/Style 换皮]
    C --> E[足迹地图联动]
    F[SDXL / Midjourney API] --> D
```

- **多模态 AI 自动结构化**：用户随手拍一张模糊、褪色的老票根，后台直接走 **DeepSeek-VL / GPT-4o 接口**，无情提取：`{类别: 演唱会, 艺人: XXX, 时间: 2026, 地点: 东京巨蛋, 席位: A席}`。
    
- **智能连带引力**：机票/车票与门票的时间、地点自动关联，AI 自动判定这是一个“Travel & Live Event Group”，拒绝零散堆放，自动归置到一个主题夹。
    
- **老旧门票“赛博焕新”**：
    
    - **2D 翻新**：OCR 提取核心元素后，调用后台轻量级 SD（或 ComfyUI 托管管线），将原本杂乱、褪色的实景门票背景，重绘成一张**果冻感、镭射边缘、纸雕阴影**的 2D 艺术卡面。
        
    - **正反面合成**：前端将正面（AI 焕新卡面）与背面（原始票根照片，保留那一抹具有时代感的热敏纸字迹）合成一张逻辑卡，支持 3D 翻开、掀开。
        

## 3. 工程施工 Brief：轻量级 Flutter 极速交付方案

坚决拒绝在后台写重度渲染引擎，包体积必须压在 30MB 以内，所有高颜值表现全靠前端纯位图套利和客户端动态拼装。

- **视觉定调**：**纸雕可爱风 + 3D 糖果果冻质感（Papercut & Candy Fusion）**。
    
- **Figma 切图与远程换皮**：
    
    - 去 Figma 社区直接白嫖一套 `Kawaii UI Kit`。利用 Frame 无损切图，将所有的卡片边框、纸雕底纹、印章挂件（机票印章、LIVE印章）切成 WebP 格式，托管在**腾讯云 COS** 上。
        
    - 前端使用 `CachedNetworkImage` 加载，配合 `Stack` 布局动态拼装。AI 识别出是“机票”，前端自动套用 COS 上的“复古登机牌”外框；识别出是“演唱会”，套用“糖果应援棒”外框。**实现不重新提审 App 的动态换皮。**
        
- **Flutter 关键交互实现**：
    
    - **3D 翻转卡片**：直接用 `flutter_flip_card` 包，或者用 `Transform` 配合 `GestureDetector` 控制 `Matrix4.identity()..setEntry(3, 2, 0.002)..rotateY(angle)`。
        
    - **物理动态镭射高光**：利用 `sensors_plus` 获取手机陀螺仪数据。当用户倾斜手机时，通过 `ShaderMask` 配合 `BlendMode.colorDodge`（颜色减淡）或 `BlendMode.overlay`，让一抹彩虹渐变色块在卡面上流淌，100% 还原线下盲盒卡片的“镭射实体感”。
        
- **人生足迹地图**：
    
    - 放弃 Google Maps 极其昂贵的 API 计费，前端直接上 `flutter_map`（基于 OpenStreetMap）。
        
    - 机票和门票联动解锁时，在地图上拉出一条带有糖果拖尾粒子效果的航线（如：广州 $\rightarrow$ 泰国），航线终点插入那张 3D 纸雕门票。满足用户的“人生进度条”收集癖。
